# 🎮 Guess Game

A fun, responsive, and interactive web-based number guessing game built using vanilla web technologies. The application generates a random number, and the player tries to guess it while receiving instant, dynamic feedback.

## 🚀 Features

- **Modern Web Interface:** Built entirely with a clean, responsive layout using HTML and CSS.
- **Real-Time Feedback:** Instant "Too High" or "Too Low" hints powered by JavaScript.
- **Score/Attempt Tracker:** Keeps an active count of the user's attempts in real-time.
- **Play Again Option:** Easily reset and restart the game without reloading the whole page.

## 🛠️ Technologies Used

* **HTML5:** For the structured content and UI elements.
* **CSS3:** For modern styling, animations, and responsive design.
* **JavaScript (ES6):** For the game logic, random number generation, and DOM manipulation.
